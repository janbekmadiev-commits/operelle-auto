# Bekzhan Logistic: демо автоперевозок

Демо программы для логистической компании на платформе OPERELLE: сайт клиента и панель управления.

Открыть: https://janbekmadiev-commits.github.io/operelle-auto/

- `index.html`: стартовая страница с двумя кнопками и ссылкой для отправки
- `p-auto-site.html`: сайт клиента
- `p-auto-dash.html`: панель компании

Все данные демонстрационные и хранятся в браузере устройства.
